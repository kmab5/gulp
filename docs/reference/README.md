# Historical visual references

These PNG screens come from the **approved direction**, captured before the final naming and navigation update. They show the accepted bottle, palette, screen density and quick-log language. Superseded details: old brand STILLWATER, four-tab navbar, navbar background/island, static text treatment. The binding changes are in `../DESIGN_CONTRACT.md`: use **gulp**, a seamless **five-tab** bottom nav including **Review**, moving water-responsive text masking, and universal tap ripples. These images are reference art, not screenshots of the Android source in this package.

The `evidence/` directory preserves the science research documents from the earlier planning handoff. Old product names in those archival records are not the present branding.
